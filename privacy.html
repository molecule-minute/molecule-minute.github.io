Privacy Policy

Molecule Minute Autopilot · Last updated November 20, 2026 · Terms of service

Molecule Minute Autopilot ("the app") is a private publishing tool run by the owner of the Molecule Minute YouTube channel. It is used only by the channel owner, only to publish the channel's own videos. It has no other users.

What the app accesses

  • YouTube (scope youtube.upload): to upload the channel's own videos and set their title, description, tags and scheduled publish time. The app does not read comments, analytics, subscriber lists or any other YouTube data.
  • Google Drive (scopes drive.readonly and drive.file): to read new video scripts from the channel owner's own queue folder, and to save finished video files to the owner's own folder.

What the app stores

The app keeps a short record of the videos it has uploaded: the video's file name, YouTube video ID, title and publish time. The Google sign-in tokens it uses are stored as encrypted secrets in the owner's private GitHub repository and are never shared.

What the app does not do

  • It does not collect, store or share personal information about viewers or any other people.
  • It does not sell or transfer any data to third parties, and it does not use data for advertising.
  • It does not use cookies or tracking.

Google and YouTube

The app uses YouTube API Services. By using it, the channel owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

The upload record is kept only so the app never uploads the same video twice. No data from YouTube API Services is stored beyond that record, and it is not shared with anyone. If access is revoked, the owner deletes the stored tokens and the upload record within 7 days. Any data obtained from YouTube API Services is refreshed or deleted within 30 days.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions or through the Google security settings page. Removing access stops the app immediately, and its stored tokens no longer work.
